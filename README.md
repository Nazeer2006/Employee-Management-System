# Employee Management System

A full-stack Employee Management System.

## Technologies
- HTML, CSS, JavaScript
- Node.js and Express.js
- MySQL
- REST API

## Features
- Add employees
- View employees
- Update employee details
- Delete employees
- Employee database storage

## API Endpoints

GET /api/employees
GET /api/employees/:id
POST /api/employees
PUT /api/employees/:id
DELETE /api/employees/:id

## Database Setup
1. Install MySQL Server.
2. Execute database/schema.sql.
3. Optionally execute database/sample_data.sql.

## Backend Setup
1. Install Node.js.
2. Run npm install.
3. Copy .env.example to .env.
4. Configure MySQL credentials in .env.
5. Run npm start.

Backend URL: http://localhost:5000
